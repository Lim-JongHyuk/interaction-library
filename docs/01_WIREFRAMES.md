# 01. 와이어프레임 — 화면 설계

ASCII 와이어프레임. 픽셀 사양이 아니라 **배치·위계·동작 계약**이 기준이다.

## L0. 공통 레이아웃

```
┌────────────────────────────────────────────────────────────────┐
│ Header:  [Logo]        [ Search ⌘K ]          [GitHub] [◐테마] │
├──────────────┬─────────────────────────────────────────────────┤
│ Sidebar      │  Main content                                   │
│  Text        │                                                 │
│   · Shuffle  │                                                 │
│   · Jitter   │                                                 │
│   · …        │                                                 │
│  Reveal      │                                                 │
│  Scroll      │                                                 │
│  Hover       │                                                 │
│  Image       │                                                 │
│  Background  │                                                 │
│  UI & Micro  │                                                 │
├──────────────┴─────────────────────────────────────────────────┤
│ Footer: license · contributing · changelog                     │
└────────────────────────────────────────────────────────────────┘
```

- 사이드바: 240px 고정, 현재 페이지 하이라이트, 카테고리 접기/펴기.
- <1024px: 사이드바는 헤더 햄버거 → 드로어. 검색은 ⌘K 모달(모바일은 버튼).
- 다크 우선. 테마는 `next-themes`, 시스템 값 존중.

## S1. 홈 `/`

```
┌────────────────────────────────────────────────┐
│  HERO                                          │
│  <ShuffleText> "Motion, defined."  ← 자체 데모 │
│  서브카피 1줄                                  │
│  [ Browse components ]  [ GitHub ★ ]           │
├────────────────────────────────────────────────┤
│  카테고리 진입 카드 그리드 (7개, 아이콘+개수)  │
├────────────────────────────────────────────────┤
│  New & Popular  (카드 6개, 호버 시 모션 재생)  │
└────────────────────────────────────────────────┘
```

- 히어로의 모션은 등록된 registry 컴포넌트를 실제로 import해서 사용(도그푸딩).

## S2. 카탈로그 `/components`

```
┌────────────────────────────────────────────────┐
│ [All ▾category] [tag chips…]      [ Search ]   │
├──────────┬──────────┬──────────┬───────────────┤
│ Card     │ Card     │ Card     │  …3~4열 그리드 │
│ ┌──────┐ │          │          │               │
│ │poster│ │  ← 기본은 정적 포스터              │
│ └──────┘ │     hover/in-view 시에만 모션 마운트│
│ name     │                                     │
│ trigger⚡ tags                                 │
└──────────┴──────────┴──────────┴───────────────┘
```

- 카드 클릭 → 상세. 카드 전체가 링크, 내부에 별도 버튼 없음.
- 필터 상태는 URL 쿼리(`?category=text&tag=hero`)와 동기화.

## S3. 컴포넌트 상세 `/docs/[category]/[slug]` ★핵심 화면

```
┌────────────────────────────────────────────────────────────┐
│ Shuffle Text                          [trigger: in-view]   │
│ 설명 1줄 · tags · deps: motion                             │
├───────────────────────────────┬────────────────────────────┤
│ ① PREVIEW CANVAS              │ ② PARAM STUDIO             │
│ ┌───────────────────────────┐ │  duration  [──●──] 0.6s    │
│ │                           │ │  stagger   [─●───] 0.03s   │
│ │      Shuffle Text 데모    │ │  shuffles  [──●──] 4       │
│ │                           │ │  charset   [ A-Z ▾]        │
│ └───────────────────────────┘ │  [ Reset ]                 │
│ [▶ Replay] [▦ 격자] [◐ bg]   │                            │
├───────────────────────────────┴────────────────────────────┤
│ ③ TABS:  [ Usage ] [ Source ] [ Install ]                  │
│  Usage  : codegen 결과 — 스튜디오 값이 실시간 반영  [Copy] │
│  Source : registry/text/shuffle.tsx 전문 (shiki)    [Copy] │
│  Install: CLI 명령 1줄 / Manual 스텝                [Copy] │
├────────────────────────────────────────────────────────────┤
│ ④ MOTION SPEC 표: trigger·params·a11y·credits              │
├────────────────────────────────────────────────────────────┤
│ ⑤ Related components (같은 카테고리 3~4개 카드)            │
│ ← prev component                        next component →   │
└────────────────────────────────────────────────────────────┘
```

동작 계약:
- 스튜디오 값 변경 → 프리뷰 props 즉시 반영 + Usage 코드 문자열 재생성. 둘의 소스는 동일한 state 하나.
- Replay = 프리뷰 컴포넌트 `key` 증가로 리마운트.
- <1024px: ①/② 세로 스택(프리뷰가 위).
- URL에 파라미터 직렬화(`?duration=0.8`)는 P2 범위 외 — TODO 주석만.

## S4. 시작하기 `/docs/getting-started`

순서: 소개 → 요구사항(React 18+, Tailwind) → Manual 설치 흐름 → CLI 흐름 → reduced-motion 정책 안내. 정적 MD 수준이면 충분, 특수 컴포넌트 불필요.

## S5. 검색 모달 (⌘K)

- 전 스펙의 name/tags/description 대상 클라이언트 검색(fuse.js).
- 결과 행: 카테고리 뱃지 + 이름 + 매칭 태그. Enter → 상세 이동.
